# 🏊 Swimming Pool Management System (Full Stack)

### 📄 Overview

This is a comprehensive **Full Stack application** designed to manage all operational aspects of a modern swimming pool or sports club. The system streamlines member registration, fee collection, class scheduling, and resource allocation.

### ✨ Key Features

The application incorporates complex business logic and data management modules:

* **Member Management (CRUD):** Complete registration, profile management, and status tracking for all members.
* **Subscription & Fees Tracking:** Automated billing, payment status updates, and historical fee record keeping.
* **Class & Scheduling:** Managing different swimming classes, assigning instructors, and handling time slot bookings.
* **Role-Based Authentication:** Separate dashboards and access controls for Administrators and Members.
* **Reporting:** Generating reports on membership growth, revenue, and class occupancy.

### 🛠️ Technology Stack

This project showcases end-to-end development using enterprise-standard technologies:

| Category | Technology | Purpose |
| :--- | :--- | :--- |
| **Backend API** | Spring Boot (Java) | Developing secure and scalable RESTful APIs for business logic. |
| **Database** | MySQL | Reliable and structured data storage for members and transactions. |
| **Frontend UI** | Angular | Building a dynamic, responsive, and data-driven user interface. |
| **Persistence** | Spring Data JPA / Hibernate | Managing database interaction efficiently. |

This project demonstrates expertise in building a robust, commercial-grade application from scratch. It confirms proficiency in:
